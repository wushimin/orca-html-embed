# 截图与操作演示

本目录供项目 README 引用，展示插件在真实虎鲸笔记中的界面和操作结果。

- 采集日期：2026-11-26。
- 环境：Windows、Orca Note 1.101.0、Orca HTML Embed 1.0.1。
- 内容：仓库的 [interactive-demo.html](../../examples/interactive-demo.html)，采用原创虚构数据。
- 操作方式：从 `/HTML` 菜单插入，将示例完整源码粘贴到编辑器并保存。文件导入是另一个可用入口，本次截图展示粘贴方式。
- 图片仅做裁剪与等比例缩放；动图在截图外添加步骤文字，按操作顺序循环播放，属于分步演示，不是连续录屏。

| 文件 | 展示内容 |
| --- | --- |
| `insert.png` | 斜杠菜单的 HTML 嵌入入口 |
| `editor.png` | 源码、标题、选项和保存按钮 |
| `embedded.png` | 保存后的三个示例项目 |
| `interaction.png` | 已完成筛选及示例 C 的详情 |
| `expanded.png` | 展开查看，保留筛选和详情 |
| `walkthrough.gif` | 插入 → 粘贴保存 → 显示 → 筛选 → 详情 → 展开 → 重载 |

采集时实际检查了源码保存、显示、筛选、详情点击、展开/收起与重载。重载后恢复三个项目及初始提示，符合网页临时交互状态不持久化的设计。这次文档补充没有重复执行完整的撤销、重做或应用重启验收；历史完整验收范围见主 README。

公开媒体不含个人笔记侧栏、原始用户测试资料、账号信息或本地资源路径。历史验收原图与诊断记录仍留在本地。
