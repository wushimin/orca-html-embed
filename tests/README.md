# 测试

## 可复现单元检查

需要 Node.js 20 或更高版本，无需安装 npm 依赖。

```sh
npm run build
npm test
```

`unit.test.mjs` 覆盖高度约束、UTF-8 和文件大小、转义、仓库资源路径、块内读取、并发读取及失败重试、原文和派生预览大小限制隔离、发行入口与源码一致性。

## 手动桌面验收

在一个专用测试页面中进行，避免改变已有笔记。

1. 安装并启用插件，导入仓库内 `examples/interactive-demo.html`。
2. 检查三个项目卡片；点击“仅看已完成”应剩两个，点击项目应显示详情；“重置演示”恢复三个。
3. 展开、收起、重载；编辑标题和高度，保存后分别撤销和重做。
4. 导出 HTML，与输入文件比较字节或 SHA-256。
5. 完整退出并重新启动虎鲸笔记，回到测试页，检查内容及交互恢复。

已完成的 1.0.1 实机验收范围见主 README。为避免暴露私人笔记及意外操作他人的真实库，本仓库不发布本地桌面诊断脚本、输入资料、截图或原始报告。单元测试通过不能替代桌面验收。
